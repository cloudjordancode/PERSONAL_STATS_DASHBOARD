# Personal Stats Dashboard

**Module:** 6 — Web Essentials & Streamlit
**Estimated time:** 30 minutes

## Objective

Build a wide-layout Streamlit dashboard using columns, metrics, tabs, and expanders with sidebar controls.

## What You'll Build

A personal stats dashboard that demonstrates Streamlit's layout components. The app uses `st.set_page_config(layout="wide")` for a full-width layout. The sidebar contains at least two control widgets (e.g., selectbox, radio). The main area includes a 3-column metrics row using `st.metric()` with delta values, two tabs ("Overview" and "Details"), and an expander with supplementary content. All data can be hardcoded.

## Reference Code

The starter file (`starter.py`) provides a scaffold with TODOs — fill in each section, then compare with the solution.

## Running

```bash
streamlit run starter.py
```

## Deliverable

A wide-layout Streamlit dashboard with sidebar controls, metric cards, tabs, and an expander.
